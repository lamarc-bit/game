# MazeQuest Mini

MazeQuest Mini is a small browser-based top-down puzzle adventure created using AI-assisted vibe coding.

The player explores a single maze, solves simple environmental puzzles, collects rewards, avoids hazards, and reaches the exit.

## Features

- One complete maze level
- One controllable player character
- WASD and arrow-key movement
- Wall and obstacle collision
- Locked door puzzle
- Collectible key
- Floor switch puzzle
- Switch-controlled gate
- Trap area
- Collectible crystals
- Start menu
- How to Play screen
- In-game HUD
- Restart functionality
- Level completion screen

## Controls

- W / Arrow Up — Move up
- S / Arrow Down — Move down
- A / Arrow Left — Move left
- D / Arrow Right — Move right

## Puzzles

### Key and Locked Door

A locked door blocks part of the maze.

The player must explore the maze, find the key, and collect it before the door can be opened.

### Floor Switch and Gate

A floor switch controls a gate in another part of the maze.

When the player activates the switch, the gate opens and allows access to a new area.

### Trap Area

The maze contains a hazard area with traps.

Touching a trap gives visual feedback and resets the player to a safe position.

## Collectibles

Purple crystals are placed throughout the maze.

Some are located along the main route while others reward exploration.

The HUD displays the number of crystals collected.

Example:

`CRYSTALS: 3 / 5`

## Objective

The player must:

1. Explore the maze.
2. Find the key.
3. Unlock the door.
4. Activate the floor switch.
5. Pass through the opened gate.
6. Avoid traps.
7. Collect crystals.
8. Reach the exit.

Reaching the exit displays the Level Complete screen.
